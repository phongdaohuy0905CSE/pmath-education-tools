Không Gian Oxyz & Vectơ Vận Tốc Thực Tế

Vẽ mặt phẳng $(P): Ax + By + Cz + D = 0$, mặt cầu $(S)$, đường thẳng tham số. Mô phỏng chuyển động thẳng đều $\vec{r}(t) = \vec{r}_0 + \vec{v}t$, tính độ lớn vận tốc $|\vec{v}|$ và tự động tính khoảng cách an toàn tránh va chạm giữa 2 máy bay.

  • Quỹ đạo hạt phát sáng & vệt đường bay 3D
  • Mũi tên vectơ vận tốc $\vec{v}$ trong không gian Oxyz
  • Đo khoảng cách tức thời $d(t) = |M_1(t) - M_2(t)|$
  • Cảnh báo va chạm an toàn hàng không $d(t) < 3\text{km}$

Đồ Thị Giải Tích & Khảo Sát Hàm Số

Vẽ chính xác đồ thị các hàm số trọng tâm THPT: hàm bậc ba, hàm phân thức bậc nhất/bậc nhất, phân thức bậc hai/bậc nhất, hàm lượng giác. Tự động tính tiếp tuyến, cực trị, điểm uốn và diện tích hình phẳng giới hạn bởi tích phân.

  • Nhập biểu thức tự nhiên: $y = x^3 - 3x + 1$, $y = \frac{2x-1}{x+1}$
  • Xác định tự động tiệm cận đứng, tiệm cận ngang
  • Mặt cong không gian 3 chiều: $z = f(x, y)$
  • Tìm giao điểm giữa đồ thị và đường thẳng

      1. Phương Trình Hình Học Giải Tích (Oxy & Oxyz)

      Đối tượng Phương trình chuẩn Tính chất & Công thức khoảng cách / Giao tuyến
      Đường thẳng 2D (d) ax + by + c = 0 hoặc y = kx + m VTPT n⃗ = (a; b), VTCP u⃗ = (-b; a). Khoảng cách từ M(x₀,y₀): d = |ax₀+by₀+c| / √(a²+b²)
      Đường tròn 2D (C) (x - a)² + (y - b)² = R² Khai triển: x² + y² - 2ax - 2by + c = 0 với R = √(a² + b² - c)
      Mặt phẳng 3D (α) Ax + By + Cz + D = 0 VTPT n⃗ = (A; B; C). Khoảng cách từ I(x₀,y₀,z₀): d = |Ax₀+By₀+Cz₀+D| / √(A²+B²+C²)
      Mặt cầu 3D (S) (x - a)² + (y - b)² + (z - c)² = R² Mặt phẳng cắt mặt cầu theo đường tròn bán kính r = √(R² - d²) khi d(I, α) < R
      Đường thẳng 3D (Δ) x = x₀ + at, y = y₀ + bt, z = z₀ + ct Chính tắc: (x - x₀)/a = (y - y₀)/b = (z - z₀)/c với VTCP u⃗ = (a; b; c)

      2. Hình Học Phẳng 2D & Điểm Đặc Biệt

      Tên hình / Đường Chu vi / Tỉ lệ Diện tích / Công thức cốt lõi
      Tam giác (△ABC) P = a + b + c ; p = P/2 S = ½·a·hₐ = ½bc·sinA = √[p(p-a)(p-b)(p-c)] = abc/(4R) = p·r
      Trọng tâm G, Trực tâm H, Tâm O, I AG = (2/3)AMₐ ; OH = 3·OG Đường thẳng Euler đi qua O, G, H ; Bán kính đường tròn 9 điểm R_E = R/2
      Hình vuông, HCN, Hình thoi, Hình thang d_vuông = a√2 ; d_HCN = √(a²+b²) S_vuông = a² ; S_HCN = ab ; S_thoi = ½d₁d₂ ; S_thang = ½(a+b)h

      3. Hình Học Không Gian 3D

      Khối 3D Diện tích xung quanh & Toàn phần Thể tích (V)
      Lập phương (a) & Hộp chữ nhật (a,b,h) Lập phương: S_xq = 4a², S_tp = 6a² ; Hộp: S_xq = 2(a+b)h V_lập_phương = a³ (AC' = a√3) ; V_hộp = a·b·h
      Hình chóp đều & Lăng trụ đứng Chóp đều: S_xq = ½·P_đáy·d (d: trung đoạn) ; Lăng trụ: S_xq = P_đáy·h V_chóp = ⅓·S_đáy·h ; V_lăng_trụ = S_đáy·h
      Trụ (r,h), Nón (r,h,l) & Cầu (R) S_xq_trụ = 2πrh ; S_xq_nón = πrl (l=√(r²+h²)) ; S_cầu = 4πR² V_trụ = πr²h ; V_nón = ⅓πr²h ; V_cầu = (4/3)πR³
